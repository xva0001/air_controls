# AirCanvas — 手勢對應表

本文件是權威的互動詞彙表。預設值同時編碼於 `aircanvas/config.py`，並且可以在兩個介面的 **Mapping**（對應）中變更。

---

## 1. 靜態姿態詞彙

MediaPipe 提供 21 個特徵點。AirCanvas 由關節角度計算手指伸展（PIP 角度 ≥ 148°，且指尖比 PIP 更遠離手腕），並由 `distance(thumb tip, index tip) / palm_scale` 計算捏合比例。

| 姿態 | 外觀描述 | 偵測規則（摘要） | 典型意義 |
| --- | --- | --- | --- |
| **指向（Point）** | 食指伸出，中指／無名指／小指彎曲 | 食指伸出；其餘三指未伸出；拇指–食指間距高於捏合門檻 | 繪圖／標註／移動空中游標 |
| **捏合（Pinch）** | 拇指與食指指尖接觸 | `pinch_ratio < 0.28 + 0.14 × sensitivity`，食指伸出 | 左鍵點擊；按住以拖曳；在標記上捏合以移除 |
| **兩指（Two fingers）** | 食指 + 中指伸出，無名指／小指彎曲 | 食指與中指伸出；無名指／小指未伸出 | 右鍵按住；頁面滑動 |
| **張開手掌（Open palm）** | 四或五根手指伸出 | 至少四指伸出，且包含食指、中指與無名指 | 導覽待命／休息／取消 |
| **握拳（Fist）** | 手掌緊閉，沒有手指伸出 | 伸出數量 ≤ 1 且不是捏合 | 結束筆畫／釋放意圖 |
| **三指（Three fingers）** | 食指 + 中指 + 無名指伸出 | 食指／中指／無名指伸出；小指未伸出 | 保留／自訂對應 |

分類優先順序為 **捏合 → 張開手掌 → 三指 → 兩指 → 指向 → 握拳**。捏合要求食指伸出，可避免拇指橫過掌心的握拳被判定為點擊。

### 時間穩定化

- 預設 `stability_frames = 5`。
- 只有當最近影格中的多數（≥ 3/5）一致時，姿態才會成為穩定姿態。
- `held_s` 回報該穩定姿態已持續多久。
- 手部消失會在 180 ms 後重設穩定姿態，避免殘留的假性持續（ghost hold）。
- 穩定器是共用的；它並未在網頁用戶端重新實作。

## 2. 情境對應表

### 螢幕模式

| 使用中的工具 | 穩定手勢 | 情境 / 額外條件 | 動作 | 回饋 |
| --- | --- | --- | --- | --- |
| **Draw（繪圖）** | 指向 | 穩定；筆畫在穩定後才開始 | 開始／繼續一筆手繪線條 | 珊瑚色光暈、手指游標、即時路徑 |
| Draw | 任何其他姿態 / 手部消失 | 筆畫進行中 | 結束筆畫；可選的智慧圓檢查 | 矯正筆畫事件 + 提示訊息 |
| **Navigate（導覽）** | 張開手掌 | 按住 280 ms，然後在單一軸向移動 > `0.115 / sensitivity` | 向上滑 → 向上捲動；向下 → 向下捲動；向左 → 上一頁（Back）；向右 → 下一頁（Forward） | 羅盤進度環、待命狀態、提示訊息 |
| Navigate | 兩指 | 同樣的按住；水平方向為主 | 向左滑 → 上一頁；向右滑 → 下一頁 | 頁面標籤 + 提示訊息 |
| Navigate | 任何非導覽姿態 | — | 解除待命；錨點重設 | 提示回到待命指示 |
| **Mouse（滑鼠）** | 捏合 | 穩定點擊姿態；180 ms 去抖動 | 左鍵按下；不再捏合時放開 | 游標變化、點擊漣漪 |
| Mouse | 捏合 + 移動 | 按住期間 | 拖曳 | 按下狀態游標、漣漪 |
| Mouse | 兩指 | 按住 420 ms | 右鍵點擊一次 | 藍色漣漪、半兩指游標 |
| Mouse | 任何姿態 | — | 游標跟隨食指指標 | 虛擬或作業系統游標 |
| Draw / Navigate / Mouse | 握拳 / 張開手掌 / 沒有手部 | — | 結束任何進行中的滑鼠按下；不會有卡住的按鍵 | 放開事件 |

**導覽動作對應：** 語義動作為 `scroll_up`、`scroll_down`、`back`、`forward`、`page_prev`、`page_next`。當 *System navigation*（系統導覽）啟用時，桌面原生橋接會將它們對應到滑鼠滾輪／Alt+Left／Alt+Right／PageUp／PageDown。網頁介面無法送出作業系統快速鍵；它會顯示手勢回饋並記錄此限制。

**滑鼠對應：** 桌面的 *Control OS mouse*（控制作業系統滑鼠）預設為關閉，並會要求確認。網頁介面一律提供虛擬游標與點擊漣漪；它無法移動作業系統游標。

### 鏡像模式

| 使用中的工具 | 穩定手勢 | 情境 / 額外條件 | 動作 | 回饋 |
| --- | --- | --- | --- | --- |
| **Annotate（標註）** | 指向 | 穩定 | 在視訊表面上繪圖 | 筆畫對齊所顯示的影格 |
| Annotate | 捏合 | — | 移除指尖下的標記（若有） | 標記消失；提示訊息 |
| **Track（追蹤）** | 指向 | 在物件周圍畫一個迴圈、閉合並停留 260 ms | 取得物件；初始化 CSRT | 薄荷色迴圈軌跡、進度環、「Object locked」（物件已鎖定） |
| Track | 指向 | 迴圈太小／未閉合 | 附提示地拒絕 | 琥珀色提示；不產生標記 |
| Track | 捏合 | 指標下方有標記 | 移除標記 | 移除該列／標記 |
| Track | 任何 | 標記在遮蔽後遺失 | 嘗試回復 2.4 秒 | 琥珀色「遮蔽／搜尋中」狀態 |
| Track | 任何 | 標記反覆出現在影格邊緣 | 確認離開視野；停止 | 「Left camera view」（已離開攝影機視野）提示訊息 |
| Track | 任何 | 標記已回復 | 恢復追蹤 | 薄荷色狀態 + 「re-acquired」（重新取得）提示訊息 |

手動移除標記也可以在 **Tracked objects**（已追蹤物件）清單中進行。移除最後一個標記並不會破壞繪圖。

## 3. 刻意的動作與錯誤防範

導覽是最容易誤觸的手勢，因此它採用五道獨立的防護：

1. **Navigate 工具**必須在使用中（或該手勢角色已被對應，且在該工具中使用）。
2. 張開手掌必須連續數個影格保持**穩定**。
3. 該姿態必須**持續** `nav_hold_ms`（預設 280 ms）。
4. 待命期間錨點會持續跟隨手部，因此一般的位置調整不會被算作滑動。待命之後的移動必須超過位移門檻。
5. 滑動只會觸發**一次**，之後必須放開該姿態，並等待冷卻時間（預設 1 秒）結束。

常見的實作錯誤是採用單一影格的速度門檻；這會在手的抖動與自然的位置調整時誤觸。AirCanvas 刻意將「待命」與「滑動」分離。

就繪圖而言，穩定器加上「指標必須在移動中」（而非只是單一點）的要求，可減少誤產生的點。單點筆畫會以原因 `single point` 被丟棄。

## 4. 智慧圓辨識

| 參數 | 預設值 | 意義 |
| --- | --- | --- |
| 最少點數 | 12 | 避免嘗試擬合一個小點 |
| 最小路徑長度 | 0.14 正規化單位 | 拒絕短小的刻痕 |
| 閉合度 | 後半段最佳距離 ≤ 0.24 × bbox 對角線 | 接受自然的超出 |
| 角度覆蓋率 | 12 個分箱中 ≥ 72% | 要求涵蓋迴圈的大部分 |
| 圓度 | ≥ 0.48 | 可容忍手部晃動 |
| 長寬比 | 0.55–1.9 | 支援寬形舞台與 16:9 視訊 |
| 擬合置信度 | ≥ 0.54 | 拒絕模稜兩可的迴圈 |
| 輸出 | 96 點的閉合圓 | 以 `kind="circle"`、`corrected=true` 提交 |

即使畫布不是正方形，渲染器仍會將矯正後的筆畫繪製成真正的實際圓形。在工具列／檢視面板中關閉 **Smart shapes**（智慧形狀），即可保留每一處手繪的晃動。此選項僅套用於新筆畫；既有的已提交筆畫會保留，且可復原。

## 5. 自訂

每個角色都可以指派其中一種靜態姿態（「none」／「unknown」除外）：

| 角色 | 預設 | 設定鍵 | UI 位置 |
| --- | --- | --- | --- |
| 繪圖 / 標註 | 指向 | `gesture.draw_pose` | Mapping 格狀設定 |
| 左鍵點擊 | 捏合 | `gesture.click_pose` | Mapping 格狀設定 |
| 右鍵點擊 | 兩指 | `gesture.right_click_pose` | Mapping 格狀設定 |
| 導覽待命 | 張開手掌 | `gesture.nav_pose` | Mapping 格狀設定 |
| 頁面滑動 | 兩指 | `gesture.page_pose` | Mapping 格狀設定 |

其他控制項：

| 設定 | 預設 | 範圍 | 效果 |
| --- | --- | --- | --- |
| 捏合靈敏度 | 1.00 | 55–180% | 數值越大，容忍越寬的拇指–食指間距 |
| 指標平滑 | 0.62 | 0–95% | 越高 = 越平穩但延遲越大（One Euro 濾波截止頻率） |
| 導覽按住時間 | 280 ms | 120–900 ms | 越長 = 待命越刻意 |
| 姿態穩定度 | 5 個影格 | 3–11 | 越大 = 誤判越少，但延遲越高 |
| 右鍵按住時間 | 420 ms | 200–1500 ms | 越長 = 右鍵點擊越刻意 |
| 慣用手 | Auto（自動） | Auto / Left / Right | 篩選 MediaPipe 候選 |
| 左手版面 | 關閉 | 開/關 | 將手勢檢視面板移到左側、工具列移到右側（網頁與桌面皆然）；慣用手本身絕不會反轉繪圖座標 |
| 鏡像攝影機 | 開啟 | 開/關 | 自拍視角；擷取與顯示共用同一個原點 |
| 顯示特徵點 | 開啟 | 開/關 | 僅顯示骨架覆蓋層；不影響辨識 |

所有設定都由 `AppConfig` 驗證並持久化（桌面使用設定檔 JSON；伺服器端則依每個網頁 session 保存，新的瀏覽器 session 會重設）。

## 6. 鍵盤與滑鼠替代操作

每個主要動作都有一條非手勢的操作路徑：

- 選擇工具後直接在舞台上以滑鼠繪圖／標註。
- 模式／工具快速鍵（`1`、`2`、`D`、`N`、`M`、`A`、`T`）。
- 復原／重做（`Ctrl+Z`、`Ctrl+Shift+Z`／`Ctrl+Y`）與匯出（`Ctrl+S`）。
- 追蹤標記可用明確的 × 按鈕移除；全部清除則使用按鈕。
- 導覽動作可作為 UI 狀態與桌面作業系統快速鍵使用；開啟／使用應用程式不需要任何手勢。
- 攝影機錯誤有「重試」與「模擬視訊流」作為後備。
- 新手導引／說明可透過 `F1` 與說明按鈕存取。

## 7. 已知的手勢限制

- 在遮蔽或邊緣影格中，慣用手標籤可能模稜兩可；「Auto」會依置信度／中心性排序，並回退到最佳候選。
- 連指手套、手套或非常昏暗的光線都可能降低特徵點品質。
- 在 16:9 攝影機上畫出的實體圓是正規化後的橢圓；辨識可容忍此情況，而矯正後的結果會以圓形渲染。
- 捏合是由拇指–食指的接近程度加上食指伸展所定義。習慣以彎曲食指捏合的使用者，可能偏好重新對應或提高靈敏度。
- 兩指右鍵與兩指頁面滑動共用同一種姿態；它們是依**使用中的工具**（滑鼠 vs 導覽）區分，而非依外觀。
- 選取刻意設計為兩階段（迴圈 + 停留），操作上可能比單次捏合更慢；這是為了抵抗誤觸而做的主要取捨。
