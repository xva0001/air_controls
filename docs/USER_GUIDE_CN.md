# AirCanvas — 使用指南

歡迎使用 AirCanvas。你可以在空中繪畫、在相機影像上標註、移動游標、以刻意揮手手勢進行導覽，並圈選物件加以追蹤。所有功能都在本機執行。

本指南涵蓋桌面應用程式與瀏覽器介面。

---

## 1. 啟動應用程式

### 桌面版

在本工作站請使用已驗證的**全局 Python 3.15.1**，並在一般 PowerShell 視窗中執行：

```powershell
run_desktop_global.cmd
# 等價指令：
python run_desktop.py --camera-backend msmf --no-onboarding
```

在乾淨機器上使用 venv 時：

```powershell
python run_desktop.py
```

- **相機**會自動開啟。若沒有相機，請選擇 **使用模擬影像來源**（Use simulated feed），或以滑鼠繪畫。
- 若 MSMF／DSHOW 需要切換，請到 **System → Camera backend**。
- 在 **System → Hand landmark model** 可切換 MediaPipe、RTMPose-Hand 與自訂 21 特徵點 YOLO Pose `.pt`。狀態列會指出缺少什麼；詳見 [HAND_MODEL_BACKENDS_CN.md](HAND_MODEL_BACKENDS_CN.md)。
- `--demo` 會立即啟動具標示的模擬影像來源。
- `--mode mirror --tool track --demo` 會直接進入物件追蹤。
- 相機存取必須在程式代理沙箱之外執行；否則 Windows 可能不讓程序看到裝置。

### 網頁版

```powershell
python run_web.py --open
```

- 跳出提示時，允許瀏覽器使用相機。
- 沒有相機？請選擇 **模擬影像來源** 或 **以滑鼠繪畫**。
- 相機存取需要 `localhost` 或 HTTPS。請勿透過一般 HTTP 的區域網路 IP 開啟服務。

## 2. 30 秒快速上手

1. 在頂部選擇 **螢幕** 或 **鏡像**。
2. 在左側選擇工具。
3. 把手展示在相機前。等待手部骨架與姿勢名稱出現。
4. **指向** 以繪畫。刻意畫一個迴圈並短暫停住；智慧圖形會將其整理成圓形。
5. **捏合** 以點擊、拖曳或移除標記。
6. **張開手掌、按住，然後揮手** 以導覽。
7. 在「鏡像 → 追蹤」中，圍繞物件畫一個迴圈並保持不動，以開始追蹤。
8. 若發生錯誤，隨時使用 `Ctrl+Z`。

## 3. 模式

### 螢幕模式

- **內建畫布**（桌面版與網頁版）：在米色畫板上繪畫。
- **桌面覆蓋層**（僅桌面版）：以透明、可點擊穿透的圖層，在其他應用程式上繪畫。小型浮動工具列可控制復原、清除與結束。
- **導覽**：張開手掌揮手；雙指翻頁。
- **滑鼠**：虛擬/作業系統游標，捏合點擊/拖曳。

### 鏡像模式

- **標註**：直接在相機影像上繪畫。標註會與視訊保持對齊。
- **追蹤**：圍繞物件畫一個迴圈，按住以選取，然後移動物件，觀察標記跟著移動。系統可處理遮擋；物件離開畫面時會停止追蹤。

## 4. 工具一覽

| 工具 | 手勢 | 效果 |
| --- | --- | --- |
| 繪畫 | 指向 | 自由手繪筆畫 |
| 導覽 | 張開手掌 + 按住 + 揮手 | 捲動 / 返回 / 前進 |
| 導覽 | 雙指 + 按住 + 水平揮手 | 上一頁 / 下一頁 |
| 滑鼠 | 捏合 | 左鍵點擊；保持捏合以拖曳 |
| 滑鼠 | 雙指按住 | 右鍵點擊 |
| 標註 | 指向 | 在相機影像上繪畫 |
| 追蹤 | 指向畫圈 + 按住 | 選取並追蹤物件 |
| 追蹤 | 在標記上捏合 | 移除標記 |

快速鍵：`1` 螢幕、`2` 鏡像、`D` 繪畫、`N` 導覽、`M` 滑鼠、`A` 標註、`T` 追蹤、`F1` 說明、`Ctrl+Z` 復原、`Ctrl+Shift+Z` 重做、`Ctrl+S` 匯出。

## 5. 可靠辨識的技巧

- 使用均勻的正面光源；避免背後有明亮的窗戶。
- 將整隻手保持在畫面內，與相機距離約 40–100 公分。
- 姿勢要維持片刻。穩定器會刻意忽略單一影格的閃動。
- 導覽手勢進入待發狀態時不要移動手；等圓環填滿後再移動。
- 畫圓時，請以單一連續迴圈繪製並短暫停住。容許稍微過衝。
- 追蹤時，請圈住整個物件並保持不動，直到標記出現。
- 若手部看起來是鏡像的，請在檢查器中切換 **鏡像相機**。
- 慣用左手嗎？啟用 **左手版面**，將控制項移到你慣用的一側。

## 6. 調校

開啟檢查器（桌面版為右側面板；網頁版在窄螢幕下為 **控制項**）。

| 控制項 | 調整方式 |
| --- | --- |
| 捏合靈敏度 | 若捏合未觸發則調高；若太容易觸發則調低 |
| 游標平滑 | 數值越高越平穩，但延遲越大；越低越靈敏 |
| 導覽按住時間 | 若揮手誤觸則調高；若導覽感覺太慢則調低 |
| 姿勢穩定度 | 影格數越多 = 誤觸越少，但延遲越大 |
| 繪畫/點擊/右鍵/導覽/翻頁對應 | 指派你覺得順手的姿勢 |
| 慣用手 | 自動、左手或右手 |
| 鏡像相機 | 自拍視角與標註對齊 |
| 顯示特徵點 | 僅顯示骨架疊層；隱藏時偵測仍會持續 |

桌面版的作業系統滑鼠與系統導覽預設為關閉。啟用時會顯示確認對話框，說明相關風險。瀏覽器工作階段無法啟用作業系統控制。

---

## 7. 復原、清除、匯出

- 復原/重做涵蓋筆畫、圖形修正、擦除與清除。歷史記錄依畫布區分（螢幕與鏡像）。
- 清除是可逆的：若誤按清除，請按 `Ctrl+Z`。
- 匯出 PNG（`Ctrl+S`）會以 1920×1080 渲染作品，且不含介面元素。在鏡像模式下，會包含目前的相機影格與標註/標記。
- 追蹤標記須明確移除，無法透過復原移除；請使用已追蹤物件清單中的 ×，或在標記上捏合。

## 8. 相機疑難排解

若桌面應用程式無法開啟相機，請先執行獨立診斷工具：

```powershell
python scripts/diagnose_camera.py --max-index 3
```

它會針對相機 0–3 嘗試所有相關的 OpenCV 後端，並顯示裝置是否能開啟且實際傳送影格。本版本在 Windows 上依序嘗試 **MSMF → DSHOW → OpenCV 自動**；確切錯誤也會寫入應用程式記錄檔。相機後端可在 **系統 → 相機後端** 中變更，無需重新啟動應用程式。

| 問題 | 處理方式 |
| --- | --- |
| `VIDEOIO(DSHOW) ... can't be used to capture by index` | 通常表示沒有偵測到任何 DirectShow 裝置。請嘗試 **Media Foundation** 後端，再試 **OpenCV 自動**；並執行診斷工具 |
| 找不到相機 | 檢查 Windows 設定 → 隱私權與安全性 → 相機；檢查裝置管理員；關閉其他相機應用程式；使用模擬影像來源 |
| 相機在瀏覽器中可用，但桌面版不可用 | OpenCV/Windows 在此工作階段中看不到該裝置。請使用網頁介面，或修正桌面版的相機隱私權/後端設定；並執行診斷工具 |
| 權限遭拒（網頁版） | 點選網址列的相機圖示並允許，然後按 重試 |
| 透過區域網路 HTTP 開啟頁面 | 請使用 `http://localhost:8765` 或 `https://`；相機需要安全內容環境 |
| 相機忙碌 | 關閉 Teams/Zoom/OBS 虛擬相機；再重試 |
| 相機已開啟但沒有影格 | 嘗試不同的後端/索引；部分虛擬相機會回報已開啟，卻從不傳送影格 |
| 未偵測到手部 | 改善光線、展示整隻手、靠近一點，並檢查慣用手設定 |
| 手勢太容易觸發 | 調低靈敏度，提高穩定度/導覽按住時間 |
| 手勢未觸發 | 調高捏合靈敏度、延長姿勢維持時間，並檢查對應設定 |
| 追蹤遺失物件 | 避免完全遮擋；讓物件保持在畫面內；重新選取 |
| 桌面覆蓋層遮住所有內容 | 使用浮動工具列的結束；畫布依設計為可點擊穿透 |
| 網頁服務中斷 | 重新啟動 `run_web.py`；頁面會自動重新連線 |

## 9. 隱私

AirCanvas 會在電腦的記憶體中處理相機影格，不會上傳或儲存這些影格。網頁服務綁定本機迴路位址，且沒有遙測功能。模擬影像來源一律標示為 `SIMULATED`，因此螢幕截圖與示範不會被誤認為即時相機輸入。

若將網頁服務暴露至網路，你將承擔驗證、TLS 與隱私責任，而這個以本機優先的專案並不提供這些能力。

---

## 10. 鍵盤與滑鼠備援方式

你不需相機也能使用應用程式：

- 使用滑鼠繪畫/標註。
- 使用鍵盤快速鍵切換模式、工具、復原/重做、說明與匯出。
- 使用追蹤清單的 × 按鈕移除標記。
- 選擇模擬影像來源，以查看完整的手勢回饋與追蹤流程。

若因運動疲勞或光線而難以使用手勢，請調整靈敏度/按住時間，或改用滑鼠繪畫。應用程式從設計之初就考慮到這種搭配，並非事後補救。
